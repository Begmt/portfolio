# Редизайн по AI Design Skills

9 ноября 2026. Исходный коммит `eff8679`. Изменения только внутри portfolio.

## Применённые скиллы

- [landing-page-design](https://github.com/elayadesign/ai-design-skills/tree/main/skills/landing-page-design) из указанного пользователем репозитория.
- [redesign-existing-projects](https://github.com/elayadesign/redesign-skill/tree/main/skills/redesign-existing-projects), рекомендованный первым скиллом для существующих сайтов.

Копии инструкций и MIT-лицензии сохранены в `audit/design-reference`. Это рабочие справочные копии внутри проекта, не глобальная установка в профиль Codex. Использованы стратегия одной основной заявки, Manrope, нейтральная палитра, именованные типографические стили, асимметричная композиция, локальные Phosphor SVG и контролируемое движение. Стек остаётся HTML/CSS/JS без сборки и новых JS-библиотек.

Аудит перед правками: синие поверхности и одинаковые карточки не разделяли уровни важности; крупный терминал конкурировал с предложением; доказательство результата было ниже первого экрана; раскрывающееся мобильное меню было тесным. Выбрана классическая структура с hero и аргументами ниже: бизнес-аудитория сначала видит предложение и результат, затем схемы и интерактивные детали.

Границы правил: исходные тексты и корректные русские дефисы в них сохранены согласно прежнему заданию; новые отзывы/контакты/цены/гарантии не создавались. Предписания скилла о «бесплатном пробном периоде»/гарантии не применялись без фактов. Моноширинная пара сохранена для технических подписей по исходному брифу. Прозрачность начального состояния слогана повышена для WCAG AA: 35% в тёмной и 45% в светлой теме вместо неконтрастного более бледного состояния. Исключение grid-раскрытия кейсов из ограничения transform/opacity осталось из исходного задания.

## Проверки

[check.cjs](check.cjs) и [results.json](results.json): 360,390,768,1024,1440 px; нет горизонтальной прокрутки; видимые ссылки/кнопки/summary ≥44×44; CTA в первом мобильном экране; Manrope загружен. Пройдены мобильное меню/inert/Tab/Esc, вкладки обработчиков, фильтры, полное раскрытие кейса, lightbox, сценарий экосистемы, ROI-вектор 2×10×52×100=104000 ден. ед./год, визард, Ctrl+K и тема. Runtime-ошибок и HTTP ≥400 нет. Без JS видны кейсы, слоган и итоговые 150/99.9/7/50.

[check-motion.cjs](check-motion.cjs) и [motion-results.json](motion-results.json): закрытый код не печатается; после раскрытия цикл переключается, фокус останавливает его; слоган раскрывается, изменение reduce убирает движение; touch-меню и сохранение темы после перезагрузки работают.

`node --check` для script.js/interactions.js/design.js и `git diff --check` выполнены. Сравнения — в реальном Chrome/Playwright, с эмуляцией размеров; проверки физических телефонов не заявляются.
