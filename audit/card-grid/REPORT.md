# Сетка кейсов и персональный профиль

9 ноября 2026. Работа выполнена только в отдельном репозитории `portfolio`. Родительский «Парсер» не изменялся. По дополнительному поручению владельца добавлены профиль из резюме и подходящие проекты GitHub.

## Сетка

| Before | After |
|---|---|
| Две неравные колонки; первая карточка занимала два ряда и оставляла большой провал слева. | `style.css`: три равные колонки от 1024 px, без `grid-row: span 2`; до 1023 px одна колонка с промежутками 16 px. |
| Первая карточка имела увеличенные отступы, заголовок и метрику. | Единые размеры текста и отступы у всех трёх карточек. Закрытые карточки растягиваются до общей высоты, кнопки выровнены по нижнему краю через flex и `margin-top:auto`. |
| Асимметрия задавала расположение второго и третьего кейсов. | Все три идут в исходном порядке в одном ряду. При раскрытии кейса соседние карточки не растягиваются до высоты его содержимого; фильтры, клавиатура и lightbox сохранены. |

## Профиль и проекты

| Before | After |
|---|---|
| Заглушки имени, представления, фотографии и профилей. | `index.html`, `style.css`: Бегмат Ирматов, специализация, Ташкент, описание работы, NEX GROUP/iCORP с датами и образованием из резюме; ссылка на GitHub. Вместо отсутствующей фотографии — текстовая монограмма «БИ». Список опыта оформлен без стандартного отступа списка. |
| «7 лет» в hero, статистике и description не соответствовали предоставленному резюме. | Указано внедрение CRM с 2023 года. Статичный год исключён из счётчиков через `.stat-number[data-target]` в `script.js`; no-JS проверка обновлена под 2023. Остальные существующие показатели кейсов не переписывались. |
| Заголовки метаданных и structured data были обезличены. | Имя в title/OG/Twitter, актуальный description, JSON-LD Person со специализацией и ссылкой GitHub. |
| Публичные репозитории не были представлены на сайте. | Отдельный раздел `#projects` с двумя карточками: МойСклад Hub и Milliy Market. Назначение и стек взяты из кода; Milliy Market явно обозначен концептом с демо-оформлением заказа. На мобильных карточки проектов стоят друг под другом. |
| Не было перехода к проектам через меню и палитру. | Ссылки GitHub/проекты в desktop/mobile навигации и действие в Ctrl/Cmd+K. Существующие якоря сохранены. |

Источники: переданный владельцем PDF резюме; [профиль Begmt](https://github.com/Begmt); [moysklad-hub / package.json](https://github.com/Begmt/moysklad-hub/blob/main/package.json) и [sync-engine.ts](https://github.com/Begmt/moysklad-hub/blob/main/src/services/sync-engine.ts); [milliymarket / page.tsx](https://github.com/Begmt/milliymarket/blob/main/app/page.tsx) и [package.json](https://github.com/Begmt/milliymarket/blob/main/package.json). README milliymarket описывает starter, поэтому содержание проекта проверялось по реализации. Budget-Tracker на момент проверки пустой и не добавлен. Чужие репозитории читались через публичные URL, не клонировались, не запускались и не изменялись.

Полный PDF и его контактные поля в репозиторий не копировались. Отзывы, логотипы, цены и статус доступности остаются явными заглушками; существующие численные результаты кейсов требуют подтверждения владельца.

## Проверки

- [Сетка](local-results.json): обе темы × 360, 390, 768, 900, 1023, 1024, 1280, 1440, 1920 px. На широких экранах равны ширина/высота закрытых карточек и положение кнопок, высота сетки равна высоте одного ряда. Ниже 1024 px проверены порядок карточек и промежутки 16 px. Фильтр amo/all, раскрытие всех трёх кейсов без обрезания, lightbox, Esc/возврат фокуса и Enter для сворачивания работают. Горизонтального скролла нет. Сетка/контент также доступны без JS.
- [Профиль и проекты](local-profile-results.json): обе темы × девять ширин, включая 768/769 и 1023/1024. Контент, GitHub-ссылки, внутренние якоря, границы навигации/карточек, отсутствие горизонтального скролла. Год 2023 остаётся статичным при обычном движении; NaN нет. На 390/1440 выполнен axe для обоих новых блоков и тем: 0 нарушений WCAG A/AA, 0 ошибок JS.
- [Общий регрессионный прогон](matrix-results.json): существующий `audit/phase3/check-matrix.cjs`, обе темы × 360/390/768/1024/1440. 56 проверок axe, меню/inert/Tab/Esc, инспектор кода, фильтры, lightbox, ROI, визард и буфер обмена: 0 нарушений, 0 ошибок JS/HTTP.
- [Fallback](fallback-results.json): пять ширин без JS, конечные числа и контент видны; отказ storage/clipboard обработан. `node --check` для изменённых JS и `git diff --check` прошли.
- Снимки сетки, профиля и проектов в обеих темах на 390/1440 находятся рядом с отчётом. Для снимков блоков фиксированная навигация скрыта только на время захвата. Использована эмуляция Chrome/Playwright; физические телефоны и ручная проверка экранным диктором не заявляются.

Публикация: коммит будет отправлен в `main` и `gh-pages`, затем проверены успешный GitHub Pages deploy и соответствие отданных runtime-файлов локальным. Исторические Lighthouse фазы 3 относятся к предыдущему выпуску; новые баллы в этом отчёте не заявляются.
