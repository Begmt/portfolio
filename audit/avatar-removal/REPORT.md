# Удаление 3D-аватара

Пользователь отклонил внешний вид 3D-модели и попросил убрать её. Восстановлен прежний иллюстрированный портрет из версии `4ddc229`. Изменения ограничены portfolio.

| Before | After |
|---|---|
| 3D-сцена, вращение, жесты и подписи управления в «Обо мне». | Исходная картинка 192 × 192 и кнопка знакомства с существующим проводником. |
| Увеличенная колонка под сцену и дополнительное место под управление. | Прежняя компактная адаптивная карточка; опыт и образование занимают полную ширину ниже профиля. |
| Bootstrap, Three.js/Meshopt-модуль, GLB и лицензии в файлах публикации. | Производственные 3D-файлы удалены. Исходник и обработанные модели сохранены только в исключённом из Pages каталоге audit. |
| CI ожидал удалённые 3D-файлы. | Проверяются действующие файлы сайта. Порог каждого Lighthouse Mobile прогона ≥90 и CLS <0,1 сохранён. |
| Старые проверки распознавали только первую отвергнутую 3D-версию. | Проверка отсутствия canvas, новых органов управления и любых запросов GLB/рендерера; сравнение байтов портрета с исходным релизом. |
| В браузере мог сохраниться CSS увеличенной 3D-карточки. | Версия в адресе таблицы стилей запрашивает компактную вёрстку заново. |

Проверки: `AVATAR_RESTORE_REPORT_DIR=audit/avatar-removal node audit/avatar-restore/verify.cjs`; общая адаптивность — `node audit/lighthouse-final/verify-responsive.cjs`. Опубликованная страница проверяется с `VISUAL_CHECK_URL=https://begmt.github.io/portfolio/`. Итоговые JSON и изображения находятся в этом каталоге. Старые отчёты 3D относятся к предыдущему релизу.
