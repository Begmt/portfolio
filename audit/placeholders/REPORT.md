# Скрытие незаполненных блоков

9 ноября 2026. Работа ограничена репозиторием `portfolio`; «Парсер» не изменялся.

| Before | After |
|---|---|
| Отзывы с заголовком и логотипы показывали «ВСТАВИТЬ». | Отзывы объединены в `#testimonials` с нативным `hidden`; строка логотипов также скрыта. Блоки не занимают места и исключены из доступного дерева, в том числе без JS. |
| Форматы, цены и FAQ оставались незаполненными. | Скрыт весь раздел `#formats`. Разметка и его id сохранены для будущего заполнения; новых цен, отзывов и ответов не придумано. |
| Палитра предлагала скрытую стоимость/FAQ; scroll-spy учитывал все секции. | В палитре остаются только нескрытые разделы. Scroll-spy пропускает секции с `hidden`, поэтому скрытый formats не перехватывает активный пункт меню. |
| Hero показывал заглушку неизвестного статуса доступности. | Пустой бейдж скрыт в HTML; JS показывает его только при boolean-значении `SITE_CONFIG.available`. |
| Кнопки скриншотов всегда появлялись при JS и открывали технические заглушки. | Кнопка видна только при заданном HTTP(S)-адресе в `SITE_CONFIG.caseImages`. Подпись обычная — «Посмотреть скриншот». При ошибке загрузки показывается «Скриншот временно недоступен», без «ВСТАВИТЬ» и внутренних инструкций. |

Изменены только `index.html`, `script.js`, `interactions.js`. Для публикации отзывов/логотипов/форматов нужно заполнить соответствующую разметку и снять её `hidden`. Статус и скриншоты появляются из конфига после перезагрузки. Шаблоны сохранены в скрытой разметке для будущего заполнения; проверялось отсутствие заглушек на отображаемой странице, а не удаление истории аудитов и исходных шаблонов из репозитория.

## Проверки

[Локальный результат](local-results.json): 360, 390, 768, 1024, 1440 px; обе темы с JS и стандартная тема без JS. После раскрытия всех кейсов в видимом тексте нет «ВСТАВИТЬ», а заголовки отзывов/стоимости/FAQ отсутствуют. У скрытых блоков высота 0. Кнопки незаданных скриншотов скрыты; поиск FAQ в Ctrl+K не предлагает скрытый раздел. Активный пункт меню «Кейсы» корректен. Визард открывается, Telegram/email и отсутствие горизонтального скролла проверены.

В отдельных временных браузерных фикстурах проверены заданный статус, корректное изображение с lightbox/Esc/возвратом фокуса, ошибка изображения и запрет небезопасного протокола. Эти фикстуры не меняют конфиг сайта и не публикуют выдуманный статус/скриншоты. Ошибок JS: 0. Axe WCAG A/AA на 390/1440 в обеих темах: 0 нарушений. `node --check` и `git diff --check` прошли.

Снимки профиля без отзывов/логотипов находятся рядом с отчётом. Это функциональные снимки после клавиатурных сценариев; они могут содержать skip-link/индикатор прокрутки. Фиксированная навигация скрывалась только на время захвата блока. Использованы Chrome/Playwright, не физические телефоны и не ручная проверка экранным диктором.

После отправки коммита в `main` и `gh-pages` будет проверен успешный выпуск, соответствие отданных файлов и отсутствие видимых заглушек на опубликованном сайте.
