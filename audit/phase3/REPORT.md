# Фаза 3 — полировка и выпуск

Дата: 9 ноября 2026. Изменения ограничены отдельным репозиторием `portfolio`; родительский проект «Парсер» не изменялся. Чистые HTML/CSS/JS, без сборки и новых библиотек в браузере.

## Что завершено по фазам

- Фаза 0: [аудит исходной версии](../AUDIT.md), перечень рисков и исходный Lighthouse.
- Фаза 1: [адаптивность, семантика, базовые стили и fallback](../phase1/REPORT.md).
- Фаза 2: [сценарии экосистемы, кейсы, ROI и визард](../phase2/REPORT.md). Затем [редизайн по ai-design-skills](../redesign/REPORT.md): Manrope/Geist Mono, нейтральная палитра, бирюзовый акцент, схема в hero и новая иерархия.
- Фаза 3: общий жизненный цикл движения, исправления доступности и производительности, проверки двух тем, ширин, клавиатуры, touch и отказов API. Применены принципы локального скилла `make-interfaces-feel-better`.

## Изменения Before / After

| Before | After |
|---|---|
| Отдельные числовые анимации могли продолжаться в фоне, после закрытия диалога или смены режима движения. | Общий реестр завершает числа в конечном значении, отменяет кадры и очищает ссылки. При скрытии страницы CSS-анимации ставятся на паузу; конечные WAAPI-анимации завершаются безопасно. |
| Ручная печать кода могла пережить закрытие инспектора; учитывалась видимость всего hero. | Контролируется именно окно кода. Печать прекращается при закрытии, уходе с экрана, открытии диалога, скрытии страницы и reduce. |
| Сценарии SVG и пошаговый процесс имели разрозненные остановки. | SVG изначально на паузе, сценарии отменяются при уходе с экрана/в диалог; процесс заканчивает текущую выбранную последовательность мгновенно при reduce или уходе. Неиспользуемые SVG defs удалены. |
| Раскрытие кейсов анимировало `grid-template-rows`. | Состояние 0fr/1fr меняется сразу; содержимое и соседние карточки анимируются только transform/opacity. Сохранён визуальный якорь заголовка, фокус внутри раскрытия не обрезается. Это разрешает противоречие фаз 2/3 в исходном ТЗ в пользу правила фазы 3. |
| Диалог поверх мобильного меню мог оставлять меню открытым и возвращать фокус в скрытый элемент. | Меню закрывается до открытия диалога, снимается inert. Возврат идёт к видимому инициатору либо кнопке меню/логотипу. |
| Завершённые номера timeline в светлой теме имели недостаточный контраст. | Контрастный muted без дополнительного снижения opacity. |
| Кнопка «Назад» в визарде на 768 px имела ширину около 41 px. | Минимальная ширина 48 px и боковые отступы; проверка размеров выполняется также внутри открытых диалогов. |
| ROI принимал слишком большие целые значения; четыре output могли озвучивать каждый кадр счётчика. | Проверяются безопасные целые и предел результата; невалидный ввод сбрасывает активные счётчики. Промежуточные кадры output не live, единый status сообщает состояние расчёта; конечные результаты остаются доступны. |
| Начальная инициализация и чтения геометрии/innerText создавали длинные задачи. | Некритичные улучшения уступают поток между задачами; навигация и timeline группируют работу в кадр. Геометрия экосистемы и timeline нужна только у видимого блока. Разметка слогана создаётся при приближении, текст извлекается без принудительного layout. |

## Проверки

Нет горизонтальной прокрутки; видимые кнопки/ссылки/summary ≥44×44 во всех проверяемых состояниях; главная CTA в первом мобильном экране. Tab/Shift+Tab/Esc, вкладки Home/End, фильтры, lightbox, ROI, копирование и палитра работают. Переполнение целых ROI проверено отдельно.
- [check-lifecycle.cjs](check-lifecycle.cjs), [результат](lifecycle-results.json): автоплей кода и остановка ручной печати; разрешённые анимируемые свойства; завершение процесса при смене reduce; остановка RAF/interval и SVG при эмулированном `document.hidden`; дополнительный reflow 320 px. После 5 прогревочных и 25 рабочих циклов обработчики не растут, DOM/логи ограничены, незавершённых числовых анимаций нет. Это ограниченный стресс-прогон, а не доказательство отсутствия любых утечек.
- [check-fallback.cjs](check-fallback.cjs), [результат](fallback-results.json): без JS на всех пяти ширинах видны контент, кейсы, слоган и итоговые 150 / 99.9 / 7 / 50; CTA ведёт к контактам. Отказ localStorage/sessionStorage и clipboard не ломает страницу. CSS keyframes/transition не анимируют layout-свойства.
- [check-release.cjs](check-release.cjs), [локальный результат](local-release-results.json): совпадение 12 файлов/ассетов, сохранение обеих тем после перезагрузки, touch-переходы и существование всех внутренних якорей, открытие/закрытие диалога, общие стили и ссылка возврата 404.
- `node --check` для трёх runtime JS и `git diff --check`: без ошибок.
- Визуально просмотрены снимки мобильного и настольного hero, визарда и версии без JS; файлы находятся рядом с отчётом. Использованы Chrome и Playwright с эмуляцией размеров/touch/reduce, не физические телефоны и не ручной аудит экранным диктором. Настоящие сообщения в мессенджеры не отправлялись.

## Lighthouse Mobile

Тема сохраняется через favicon-origin до навигационного замера, само приложение предварительно не загружается; storage reset отключён только для сохранения выбранной темы. ## Повторение проверок

Статический сервер из корня репозитория: `python -m http.server 8765`. Затем по очереди `node audit/phase3/check-matrix.cjs`, `node audit/phase3/check-lifecycle.cjs`, `node audit/phase3/check-fallback.cjs`, `node audit/phase3/check-release.cjs`. Тесты используют установленный Playwright/Chrome; пути в require привязаны к машине. Для matrix требуется `audit/phase3/vendor/axe.min.js` версии 4.14.0 из пакета axe-core; это только тестовый инструмент, он не загружается сайтом и не включён в Git.

Lighthouse: `node audit/phase3/measure.cjs dark http://127.0.0.1:8765/ report-name`, затем аналогично light. При другой установке указать `LIGHTHOUSE_ENTRY` до `lighthouse/core/index.js` и путь Chrome в скрипте. Для production использовать URL GitHub Pages и другой префикс отчёта. `check-release.cjs URL` сравнивает отданные runtime-файлы/шрифты с локальными, проверяет темы, touch, якоря и 404; локально он моделирует префикс `/portfolio/` для ресурсов 404.
