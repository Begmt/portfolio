15 октября 2026. Работа выполнена только в отдельном клоне `portfolio`. Исходная точка — коммит аудита `c30d575`. Фаза 2 не начата, публикации/push не было.

## Сниппеты, SEO и семантика

| Before | After |
|---|---|
| JS с недекларированным IntegrationEngine; Python с буквальной строкой ENV и без проверки HMAC; PHP с неопределённым token. | Учебные Node HTTP, Flask и PHP приёмники: env-секрет, проверка HMAC-SHA256 по явно указанному учебному контракту X-Signature, ограничение тела, ранний отказ и быстрый 200 без синхронного CRM-вызова. Python использует hmac.compare_digest, Node — timingSafeEqual, PHP — hash_equals. Unicode/неверный формат подписи в Python отклоняется до сравнения. |
| vibe_coding и визуально «готовые интеграции» без зависимостей. | Нейтральная подпись handler.ts; примеры явно названы учебными приёмниками. Пояснение: контракт подписи зависит от источника; для настоящей бизнес-обработки событие нужно надёжно сохранить в очередь до 200. Они не выдают пустое подтверждение за выполненную интеграцию. |
| Нет main/skip-link и социальных метаданных, favicon 404. | main, skip-link, последовательные заголовки в диалоге; lang=ru сохранён. Canonical, OG, Twitter card, локальные favicon.svg и social-card.png. Минимальный ProfessionalService без вымышленных адресов, рейтингов/отзывов/телефонов. |

## Проверки

`node --check script.js`, `git diff --check` — успешно.

[check.cjs](check.cjs) и [results.json](results.json): 360/390/768/1024/1440 px, без горизонтального скролла документа и пересечений узлов; видимые кнопки/ссылки/summary ≥44×44; кейс не обрезается; нативный hash, клавиатура меню/вкладок, Tab/Shift+Tab в диалоге, закрытие Esc/кнопкой/фоном и возврат фокуса; пересчёт конфигурации; финальные счётчики; копирование и отказ буфера; no-JS и reduce. Runtime-ошибок и ответов ≥400 в этом сценарии нет. Input 18px имеет полноразмерную кликабельную label-карточку; это не отдельная 18px тап-зона.

[check-final.cjs](check-final.cjs) и [final-results.json](final-results.json): no-JS меню на 360 не перекрывает hero (низ меню 166px, начало подписи hero 238px); реальные каналы корректно подключаются при тестовой подстановке CONTACTS, заглушки не ведут во внешние сервисы; три спорных исходных формулировки сохранены. Тестовые адреса существуют только в сценарии, по ним не выполнялись переходы.

[check-snippets.py](check-snippets.py) и [snippets-results.json](snippets-results.json): реальный Node HTTP-приёмник из HTML возвращает 200 для валидной подписи, 403 для неверной/отсутствующей, 413 для большого тела. Python синтаксически разобран и функция обработчика выполнена с подменой Flask request: валидная/uppercase подпись — 200, неверная/пустая/Unicode — 403. PHP проверен чтением: PHP runtime отсутствует, серверная проверка не заявляется.

Финальные кадры с отключённым движением только в контексте захвата: [390 hero](final-hero-390.png), [768 hero](final-hero-768.png), [1440 hero](final-hero-1440.png); [390 вся страница](final-full-390.png), [768 вся страница](final-full-768.png), [1440 вся страница](final-full-1440.png); [экосистема 390](final-ecosystem-390.png). Также сохранены обычные кадры всех пяти ширин, диалоги, раскрытые кейсы и no-JS. Проверка — Chrome через Playwright, эмуляция размеров, не физические мобильные устройства.

Финальный замер дизайна: [HTML](lighthouse-after-isolated.report.html), [JSON](lighthouse-after-isolated.report.json). Первый запуск был одновременно с тестами Playwright и дал Performance 59, Accessibility 100, Best Practices 100, SEO 91: нагрузка влияла на CPU, а удалённые href у незаполненных контактов провалили crawlable-anchors. Ссылки исправлены на внутренний адрес пояснения; повторный замер выполнен отдельно. Первый отчёт [сохранён](lighthouse-after.report.html), результаты не скрыты. После изолированного замера внесены только no-JS размещение меню и семантическая замена div→span внутри кнопок, проверенные отдельно; они не добавляют активной нагрузки обычному JS-пути. Тонкие настройки кэширования/сжатия зависят от хостинга и остаются финальной проверке.

Сохранены заголовок, описание услуг, кейсы/цифры и процесс. Явные изменения служебных текстов: vibe_coding→handler.ts, «Отправить конфигурацию»→«Скопировать конфигурацию», hover-инструкция→выбор узла, демонстрационные логи без имён и чисел; добавлены учебные пояснения к коду, демо-оценка сроков, сообщения о контактах/копировании. | Текущий текст | Вариант для согласования |

| «любой сложности» | «под задачи вашего бизнеса» |

Подтвердить существующие метрики, подготовить скриншоты кейсов и согласовать правила демо-оценки сроков. Заглушки оставлены видимыми для проверки; вместо них не созданы вымышленные доказательства опыта.
